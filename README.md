# Бюджетный помощник (интервальные запросы)

Программа для учёта ежедневных расходов за месяц. Пользователь может добавлять траты, запрашивать сумму за период, находить день с максимальным расходом, сортировать категории по сумме трат и отменять последнее действие.

## Возможности

- Добавление расхода с указанием дня, суммы и категории
- Запрос суммы расходов за период (день A – день B) с ответом за O(1) через префиксные суммы
- Линейный поиск дня с максимальным расходом
- Сортировка категорий по сумме трат алгоритмом вставками
- Отмена последнего добавленного расхода через стек
- Хранение трат в виде N-арного дерева (месяц → категории → траты)
- Вывод дерева трат на экран
- Список всех расходов

## Используемые структуры данных и алгоритмы

**N-арное дерево (обычное, не бинарное)** - корень дерева - месяц, второй уровень - категории (Еда, Транспорт, Жильё, Развлечения), траты хранятся как дочерние узлы категорий с указанием суммы. У каждого узла есть список дочерних элементов, что позволяет дереву разрастаться в любую сторону. При добавлении траты выполняется рекурсивный поиск нужной категории и добавление нового узла-ребёнка.

**Префиксные суммы** - массив, где каждый следующий элемент равен сумме всех предыдущих. Сумма расходов за период [A, B] вычисляется как `prefix[B] - prefix[A-1]` за O(1). Пересчитывается после каждого добавления траты.

**Линейный поиск** - для нахождения дня с максимальным расходом программа проходит по всем дням месяца (от 1 до 31) и сравнивает суммы.

**Сортировка вставками** - категории сортируются по убыванию суммы трат. Алгоритм: по очереди берётся очередная категория и вставляется на нужное место в отсортированную часть списка.

**Стек** - используется для отмены последнего действия. При добавлении расхода он помещается в стек, при отмене извлекается, и состояние восстанавливается.

## Структура проекта

- `tree.py` - класс `TreeNode` (имя, сумма, список детей), функции `find_category`, `add_expense_to_tree`, `print_tree`
- `budget.py` - класс `BudgetAssistant` со всей логикой: добавление, отмена, префиксные суммы, поиск максимума, сортировка, вывод дерева и списка расходов
- `main.py` - точка входа, меню, взаимодействие с пользователем
- `README.md` - описание проекта

## Запуск

После запуска на экран выводится меню, команда выбирается вводом её номера.

1. **Добавить расход** - запрашивается день (1-31), сумма и категория.
2. **Сумма за период** - запрашиваются дни A и B, выводится сумма расходов за этот промежуток.
3. **День с максимальным расходом** - выводится день и сумма.
4. **Сортировка категорий** - выводится список категорий от самой затратной к самой дешёвой.
5. **Отменить последний расход** - удаляет последнюю добавленную трату.
6. **Показать дерево** - выводит структуру трат в виде дерева.
7. **Показать все расходы** - выводит список всех добавленных трат.
8. **Выход** - завершает работу программы.

## Внутреннее устройство

**Класс `TreeNode` (tree.py)** - хранит имя узла, сумму (None для категорий), список детей. Методы не требуются, используется напрямую.

**Функция `find_category(node, category_name)`** - рекурсивно ищет категорию по имени, возвращает узел или None.

**Функция `add_expense_to_tree(root, category_name, amount)`** - находит категорию и добавляет в неё новый узел с суммой.

**Функция `print_tree(node, level)`** - рекурсивно выводит дерево с отступами.

**Класс `BudgetAssistant` (budget.py)** - хранит корень дерева, список категорий, массив расходов по дням, массив префиксных сумм, список всех расходов и стек для отмены.

- `update_prefix_sums()` - пересчитывает префиксные суммы.
- `add_expense(day, amount, category)` - добавляет расход, обновляет массивы и стек.
- `undo_last()` - отменяет последнее действие.
- `get_sum_by_period(day_a, day_b)` - возвращает сумму за период через префиксные суммы.
- `find_max_expense_day()` - линейный поиск дня с максимальным расходом.
- `sort_categories()` - сортировка категорий вставками по убыванию суммы.
- `show_tree()` - выводит дерево.
- `show_all_expenses()` - выводит список всех расходов.

**Функция `show_menu()` и `main()` (main.py)** - вывод меню и запуск программы.
