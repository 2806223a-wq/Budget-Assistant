# Бюджетный помощник

Программа помогает записывать расходы за месяц и быстро получать нужную информацию: сумму трат за выбранный период, день с самыми большими расходами, сортировку категорий. Все расходы хранятся в виде дерева: месяц, внутри категории, внутри суммы трат.

## Что внутри

- `main.py` — меню и запуск
- `budget.py` — вся основная логика: добавление, подсчёты, отмена
- `tree.py` — дерево для хранения трат

## Что умеет программа

1. Добавить расход - указываем день, сумму и категорию
2. Узнать сумму за несколько дней (работает быстро через префиксные суммы)
3. Найти день, в который потратили больше всего
4. Отсортировать категории по общим тратам (сортировкой вставками)
5. Отменить последнее добавление (храним действия в стеке)
6. Посмотреть всё дерево трат
7. Посмотреть все расходы списком

## Категории

По умолчанию: Еда, Транспорт, Жильё, Развлечения. Можно добавить другие в коде.
